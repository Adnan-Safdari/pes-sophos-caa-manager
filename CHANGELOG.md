# Changelog

All notable project changes are documented here.

## 0.1.0 - 2026-09-16

Initial public development release:

- systemd user services for CAA, manager, and desktop indicator
- event-driven NetworkManager integration with debounced network changes
- configurable captive-portal network detection
- automatic CAA start, stop, and IP-change restart
- session D-Bus API and CLI
- GTK/AppIndicator desktop controls with hide and restore lifecycle
- verified CAA 1.2.0 output parsing and authentication status
- original full-color and symbolic project icons
- source bootstrap and Debian, RPM, and Arch packaging templates
- automated unit and integration tests
